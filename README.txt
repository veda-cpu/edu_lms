JUST VETERINARY EDU. GROUP — V2 HTML/CSS PROTOTYPE

Files:
- index.html + styles.css: responsive website
- mobile-app.html + mobile-app.css: clickable mobile app screen-flow concept
- All files should stay in the same folder.

Open index.html for the website. Open mobile-app.html for the mobile app concept.
Mobile app flow: Welcome → Sign in / Register → Home → Courses → Course details → Lesson player → Quiz → Result → Certificate. Bottom tabs connect Home, Courses, My Learning, Live and Profile. Use the in-phone links to move between screens.

Deploy: Upload all four HTML/CSS files to the root of a GitHub repository. In Vercel select Framework Preset = Other, Root Directory = repository root, and no build command is required.

This is a visual prototype using HTML5 and CSS3 only. In-page screen transitions use CSS :target and anchor navigation. Real authentication, backend data, search, enrolment, payment, video streaming, live meeting join, quiz scoring, certificate PDF download, notifications and persistent user accounts require JavaScript and backend/API integration. Content is sample/demo content. External photos and Google Fonts need internet access.
